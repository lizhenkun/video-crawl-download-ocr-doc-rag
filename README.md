# 项目
名称: video_crawl_download_ocr_doc_rag 爬虫 - 影音截图 - OCR识别文字 - 模型总结文章

# 安装
```shell
python -m venv

# windows PowerShell 使用虚拟Python环境
.\.venv\Scripts\Activate.ps1
# windows 命令行
.\.venv\Scripts\activate.bat

# 安装所需包
uv sync

# 退出虚拟Python环境
deactivate
```
